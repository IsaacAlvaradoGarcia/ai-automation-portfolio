# AI Appointment Scheduling & CRM Automation

Automated lead capture and appointment scheduling workflow built with n8n.

This project automates the process of collecting customer information through a form, generating professional email responses, and storing appointment requests in a CRM database using Google Sheets.

---

## Project Overview

The workflow begins when a user submits a service request form.

The automation:
- captures customer data
- processes the information using AI
- sends an automatic professional email
- stores customer details inside a CRM spreadsheet
- helps streamline appointment scheduling for a computer repair business

---

---

## Workflow Logic

1. User submits a service request form
2. Workflow captures:
   - customer name
   - email
   - service request
3. AI generates a professional response
4. Gmail automatically sends confirmation email
5. Customer information is appended into Google Sheets CRM
6. Appointment request is stored for follow-up
