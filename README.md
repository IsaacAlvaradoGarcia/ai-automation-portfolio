# n8n AI Automation Learning Portfolio

This repository contains automation and AI workflow projects built while learning workflow automation, AI agents, and business process integrations using n8n.

The projects focus on:

* AI-powered chatbots
* lead capture systems
* conversational memory
* Gmail automations
* CRM integrations
* Google Sheets workflows
* webhooks and form processing
* AI routing and classification

AI-powered chatbot capable of answering frequently asked questions using Google Sheets as a knowledge base.

### Features

* FAQ routing
* AI text classification
* conversational memory
* Google Sheets integration
* session persistence

### Technologies

* n8n
* Google Gemini
* Groq
* OpenRouter
* Google Sheets API
