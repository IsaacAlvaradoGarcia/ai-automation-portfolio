# AI FAQ Chatbot

AI-powered FAQ chatbot built with n8n using Google Sheets as a knowledge base.

## Project Overview

This workflow was designed to automatically answer frequently asked questions for a computer repair business.

The chatbot can:

* answer common customer questions
* retrieve information from Google Sheets
* classify user requests
* maintain conversational context
* automate customer support interactions

---

## Features

* AI text classification
* FAQ routing
* Google Sheets integration
* conversational memory
* session persistence
* automated responses

---

## Technologies Used

* n8n
* Google Gemini
* Groq
* OpenRouter
* Google Sheets API

---

## Workflow Logic

1. User sends a message
2. AI classifies the request
3. The workflow searches relevant FAQ information
4. The chatbot generates a contextual response
5. Conversation memory is maintained during the session

---

## Challenges Solved

* AI routing logic
* conversational memory persistence
* preventing re-classification loops
* integrating Google Sheets with AI workflows
* managing session context
