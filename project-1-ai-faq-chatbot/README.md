# AI FAQ Chatbot

AI-powered FAQ chatbot built with n8n.

## Features

* FAQ routing
* AI text classification
* conversational memory
* Google Sheets integration
* session persistence

## Technologies Used

* n8n
* Gemini
* Groq
* Google Sheets API

## Workflow Overview

This chatbot answers frequently asked questions using AI and a Google Sheets knowledge base.

The workflow includes:

* AI text classification
* routing logic
* conversational memory
* FAQ retrieval system
